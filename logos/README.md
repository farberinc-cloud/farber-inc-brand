# Logos

Drop logo files here. Required:

- `farber-inc-primary.svg` — main logo
- `farber-inc-horizontal.svg` — horizontal lockup (for headers)
- `farber-inc-icon.svg` — square icon (for favicons, social avatars)
- `farber-inc-mono-black.svg` — black version for light backgrounds
- `farber-inc-mono-white.svg` — white version for dark backgrounds
- `farber-inc-stacked.svg` — vertical lockup

For each, also include PNG exports at:
- 1x (300px wide for primary, 600px for stacked)
- 2x retina (600px / 1200px)
- 3x retina (900px / 1800px)

**Naming convention:** `<company>-<variant>-<color>.<ext>`
