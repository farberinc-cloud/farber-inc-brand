## Logo System

### Primary Logo

The Farber.Inc logo pairs the **F.I** monogram with the wordmark "FARBER.INC" and the tagline "SEO | AEO | GEO".

### Logo Variations

| Variant | File | Use case |
|---------|------|----------|
| **Icon Mark** (`FI` in navy circle, gold letters) | `logos/farber-inc-icon.svg` | Favicons, app icons, social avatars, small-scale uses |
| **Wordmark** ("Farber.Inc" text only) | `logos/farber-inc-wordmark.svg` | Email signatures, text-based applications |
| **Horizontal Lockup** (`FI` mark + wordmark + tagline, side-by-side) | `logos/farber-inc-horizontal.svg` | Website headers, navigation bars, business cards |
| **Stacked Lockup** (mark on top, wordmark + tagline below) | `logos/farber-inc-stacked.svg` | Square placements, posters |
| **Primary** (full lockup default) | `logos/farber-inc-primary.svg` | Default brand mark |
| **Mono Black** | `logos/farber-inc-mono-black.svg` | Light backgrounds |
| **Mono White** | `logos/farber-inc-mono-white.svg` | Dark backgrounds (e.g., navy hero sections) |

### Logo Usage Rules

✅ **DO**
- Use approved logo files from this guide
- Maintain minimum clear space equal to the height of the "F" in Farber
- Tagline "SEO | AEO | GEO" should always accompany the logo when space permits
- Ensure sufficient contrast between logo and background

❌ **DON'T**
- Stretch, rotate, or distort the logo
- Change logo colors outside the brand palette
- Place logo on busy or clashing backgrounds
- Add effects (shadows, gradients, bevels) to the logo
- Modify the typography or create new wordmarks
- Use low-resolution logos in print

## Typography

### Font Families

| Family | Role | Weights Available |
|--------|------|-------------------|
| **Playfair Display** | Headlines & Display (serif) | Regular 400, Semi-Bold 600 |
| **Inter** | Body & UI (sans) | Regular 400, Medium 500, Semi-Bold 600 |
| **Montserrat** | Accent & Labels (geometric sans) | Semi-Bold 600, Bold 700 |

### Type Scale

| Element | Size |
|---------|------|
| H1 | 3.75rem (60px) |
| H2 | 3rem (48px) |
| H3 | 2rem (32px) |
| H4 | 1.5rem (24px) |
| Body | 1rem (16px) |
| Small | 0.875rem (14px) |
| Label | 0.75rem (12px) uppercase, letter-spacing |

### Pairing Rules

- **Playfair Display** for emotional/editorial moments (hero text, blog H1s)
- **Inter** for everything functional (UI, body, nav, buttons)
- **Montserrat** for categorical labels ("SEO", "AEO", "GEO", tag badges, eyebrow text)

## Voice & Tone

To be expanded by Randy. Provisional defaults based on positioning:

- **Authoritative but approachable** — we are experts, not gatekeepers
- **Clear, never jargon-heavy** — explain SEO/AEO/GEO terms when first introduced
- **Results-obsessed** — speak in numbers, outcomes, ROI
- **Boutique, not corporate** — avoid stiff corporate speak; we're a small team that punches above our weight
- **Forward-leaning** — call out what's changing in search/AI

### Words to use
- "visibility", "measurable", "growth", "engineer", "presence", "discovery"

### Words to avoid
- "synergy", "leverage" (overused), "best-in-class" (cliché), "guaranteed #1 ranking" (illegal in many contexts), buzzwords
